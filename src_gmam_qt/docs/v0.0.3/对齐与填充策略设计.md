# 对齐与填充策略设计（v0.0.3）

> 状态：✅ **已审定并实现**  
> 前置：v0.0.2 错误收集  
> overflow 定案：**P0**（结构体默认 `Error`，不自动改 FillChar）

---

## 1. 目标（已达成）

1. 显式对齐（含 Chars 右对齐补空格，如 `" 3"`）  
2. 自定义不足位 / 缺值填充字符（哨兵 `'\0'` = 按类型默认）  
3. `MissingPolicy` 区分未传与空串  
4. overflow 维持 P0：靠直写或 `makeNumericField` 配置 FillChar  

---

## 2. 类型与字段

### 2.1 FieldAlign

```cpp
enum class FieldAlign { ByType, Left, Right };
// ByType：Numeric→Right，Chars→Left
```

### 2.2 哨兵填充

```cpp
char padFill     = '\0';  // 不足位；'\0' → N:'0' / C:' '
char missingFill = '\0';  // 缺值整段；同上
```

```cpp
ResolvedFieldStyle resolveFieldStyle(const FieldDetail& f);
```

### 2.3 MissingPolicy

```cpp
enum class MissingPolicy {
    TreatAsMissing, // 无 key 或 trim 空 → missingFill（默认）
    EmptyIsValue,   // 仅无 key → missingFill；空串走 encode
};
```

### 2.4 FieldDetail / HeaderField 增量

```cpp
FieldAlign     align         = FieldAlign::ByType;
char           padFill       = '\0';
char           missingFill   = '\0';
MissingPolicy  missingPolicy = MissingPolicy::TreatAsMissing;
```

---

## 3. 编码行为

| 环节 | 规则 |
|------|------|
| 不足位 | 按 resolve 的 align + padFill 补齐到 length |
| 超额 Truncate | 跟随 resolve 的 align（左留左 / 右留右） |
| 超额 FillChar / Error | 同 v0.0.1 |
| 缺值 | `shouldUseMissingFill` → 整段 missingFill |
| 失败占位 | 同 missingFill（与 v0.0.2 写死 0/空格不同） |

---

## 4. overflow P0

- 结构体默认：`OverflowPolicy::Error`  
- 忘记配置 → 超长报错收集进 `errors`  
- 需要填特殊字符 → 显式 `FillChar` + `overflowFill`（常用 `'9'`）  
- `makeNumericField` 工厂默认已是 `FillChar('9')`  

---

## 5. 示例

```cpp
// "3" → " 3"
{ "cnt", FieldType::Chars, 2, 0, Rounding::Truncate, OverflowPolicy::Truncate, '9',
  FieldAlign::Right, ' ', '\0', MissingPolicy::TreatAsMissing }

// 未传 → "****"
{ "code", FieldType::Chars, 4, 0, Rounding::Truncate, OverflowPolicy::Error, '9',
  FieldAlign::Left, ' ', '*', MissingPolicy::TreatAsMissing }
```

---

## 6. 兼容性

| 旧调用 | 行为 |
|--------|------|
| 不写 align/pad/missing | 与 v0.0.1 默认一致 |
| T9 比对（调用方已格式化） | 应仍 MATCH |
| Numeric 直写未写 overflow | 仍为 Error（P0） |

---

## 7. 审查定案（摘要）

| 项 | 结论 |
|----|------|
| 哨兵 `'\0'` | 接受 |
| Align + pad + missing | 全做 |
| MissingPolicy | 做 |
| Truncate 跟 align | 是 |
| 失败占位用 missingFill | 是 |
| overflow | **P0** |
