# GMAM v0.0.2 设计说明

> 状态：✅ **已实现**  
> 范围：错误收集与日志（方案 §13）  
> 对齐 / 填充 → [../v0.0.3/](../v0.0.3/)（已实现）

---

## 1. 目标

将 v0.0.1 的「遇错即返、单条 `QString& error`」升级为：

- 字段级错误 **全部收集**
- 接口统一为 **`QStringList& errors`**
- 失败字段 **占位续跑**；最终因 errors 非空仍返回空

## 2. 接口（已定稿）

```cpp
QByteArray build(const QHash<QString, QString>& values,
                 QStringList& errors) const;
```

不保留 `QString&` 重载。`DataContentBuilder` / `HeaderBuilder` 一致。

```cpp
QStringList errors;
QByteArray data = builder.build(values, errors);
if (!errors.isEmpty()) {
    for (const QString& e : errors)
        qWarning() << e;
    return;
}
```

## 3. 错误分级

| 级别 | 例子 | 处理 |
|------|------|------|
| 整体级 | totalLength≤0、>maxLength | 立即返回 |
| 字段级 | 非法字符、超长(Error)、length 非法等 | 记入 errors + 占位后继续 |

## 4. 错误文案

```text
字段 temp（第 0 个，Numeric）：含非法字符
字段 id（第 2 个，Chars）：字符超长（7 > 6）
数据内容超长：9000 > 8162
```

实现：`GmamError.h` 的 `formatFieldError`；`encodeField` 只出短 reason。

## 5. 失败占位

v0.0.2 初版按类型写死 `'0'`/空格；**v0.0.3 起**改为使用 resolve 后的 `missingFill`（与缺值一致）。

## 6. 落地文件

- `GmamError.h`
- `DataContentBuilder` / `HeaderBuilder` / `FieldCodec` 短 reason
- 自测多错误用例
