## 1. 目标与范围

### 1.1 本版目标

- 落地可复用 **`module_tcp`**：可配置 TCP 客户端。
- 能力分层交付：
  - **P0**：连接 / 断开 / 自动重连 / 发送队列 / 发送 / Raw 接收 / 状态信号。
  - **P1**：可开关心跳（注入帧）+ wait-ack（超时重发、matcher）+ 可选长度拆帧 + 队列水位。
  - **P2**（测试工具，非核心）：本地 `127.0.0.1` + 可配端口；**带 Qt Designer `.ui` 的界面**，便于输入内容、调参联调（见测试文档）。
- 参数语义对齐 [design_03](./design_03_可配置参数清单.md)。
- 文档与 `module_tcp.pri` 同步；P0/P1 可选控制台冒烟。

### 1.2 本版核心不做（或顺延）

- TCP Server（核心不做；P2 可用独立假对端进程，另议）  
- 电文字段组报塞进 `module_tcp` / 核心依赖 GMAM  
- 写死 PES 常量进核心（`1450M`、`9999999999` 等）  
- 心跳双向 miss 检测、多窗口 ack、本地 bind（标「其后」的参数）  
- 生产业务 UI / DB（**P2 仅为测试联调界面**）

## 2. 交付切分

### 2.1 P0 — 透传客户端（优先落地）

| 能力 | 配置字段（落地） |
|------|------------------|
| 连接/断开 | `host` `port` `connectTimeoutMs` |
| 自动重连 | `autoReconnect` `reconnectIntervalMs` |
| 发送队列 | `sendQueueEnabled` `sendQueueMaxSize`（满则 Reject + 信号） |
| 发送 | `enqueue(QByteArray)` → worker 内 `write` |
| 接收 | `frameMode=Raw`：`readyRead` → 信号抛 `QByteArray` |
| 状态 | connected / disconnected / error / queueReject |
| 线程 | `Dedicated`：内部 `QThread` + worker `QObject` |
| 预留 | `TcpClientConfig` 中预留心跳/ack 字段，P0 忽略其逻辑 |

**P0 验收：** 连上 echo/假服务；enqueue 多帧能发出；断开能重连；收包信号有数据。

### 2.2 P1 — 策略层

| 能力 | 配置字段（落地） |
|------|------------------|
| 心跳 | `heartbeatEnabled` `heartbeatIntervalMs` `heartbeatFrame` / provider；不占 ack 窗；`heartbeatExpectReply=false` 即可用 |
| wait-ack | `ackEnabled` `ackTimeoutMs` `ackMaxRetry` `ackWindow=1` + positive/negative/heartbeatIgnore matcher |
| 拆帧 | `frameMode=LengthPrefix` + length 相关字段 + 可选 `frameTerminator`；`Custom` + splitter |
| 队列 | `highWaterMark` `lowWaterMark` `sendIntervalMs` `sendQueueOverflowPolicy` |
| PES | 可选 `PesAsciiFrame` 预设枚举值 + `pes_matchers` 辅助（不强制进核心 `.pri`，可 `module_tcp/profiles/`） |

**P1 验收：** 关策略=与 P0 行为一致；开心跳定时发出注入帧；开 ack 后 A 出队、N 丢弃、超时重发、超次信号；LengthPrefix 能拆多帧粘包。

### 2.3 P2 — 本地 UI 联调（测试工具）

| 项 | 约定 |
|----|------|
| 目的 | 方便输入发送内容、改 IP/端口/开关，肉眼看收发与状态 |
| 地址 | 默认 **`127.0.0.1`**，端口界面可改 |
| 界面 | **必须用 Qt Designer，保留 `.ui` 文件**，便于改布局 |
| 工程 | 建议独立 `TcpUiTest.pro`（或 Demo），`include(module_tcp.pri)`；**不把 UI 编进 module_tcp** |
| 文档 | [测试_P2_本地UI联调.md](./测试_P2_本地UI联调.md) |

**P2 验收：** 能连本机端口；输入文本/十六进制发送；日志区见收发；关键配置项可在界面改并生效。

## 3. 架构方案

```text
应用线程
  │ setConfig / connectToHost / disconnect / enqueue
  │ 信号：connected, disconnected, error, bytesReceived|frameReceived,
  │       queueHigh/Low, sendAckOk, sendNack, sendDropped
  ▼
TcpClient (门面，可活在主线程)
  │ QMetaObject::invokeMethod / 队列连接
  ▼
TcpClientWorker (QObject，Dedicated 线程)
  ├── QTcpSocket
  ├── SendQueue +（P1）AckStateMachine
  ├──（P1）QTimer heartbeat
  ├──（P1）QTimer ackTimeout
  └──（P1）FrameAssembler (Raw / LengthPrefix / Custom)
```

**原则**

1. Socket **只在** worker 线程创建与使用。  
2. `enqueue` 线程安全（互斥队列或排队到 worker）。  
3. 心跳旁路：直接 `write`，不入业务 wait-ack 槽（`heartbeatOccupyAckWindow=false`）。  
4. `ackEnabled=true` 但未设 matcher → **拒绝启用**（启动/setConfig 失败并报错）。

## 5. 对外 API 草案（审查用）

```text
class TcpClient : public QObject
{
  void setConfig(const TcpClientConfig&);
  TcpClientConfig config() const;

  void connectToHost();      // 使用 config.host/port
  void disconnectFromHost();
  bool isConnected() const;

  // 返回 false：未启用队列且失败 / 队列满 Reject 等
  bool enqueue(const QByteArray& frame);

  // P1 便捷
  void setHeartbeatFrame(const QByteArray&);
  void setAckMatchers(...);  // 或 config 内一次设齐

signals:
  void connected();
  void disconnected();
  void errorOccurred(const QString& message);
  void bytesReceived(const QByteArray&);   // Raw 或未拆帧
  void frameReceived(const QByteArray&);   // P1 拆帧后；Raw 时可与 bytes 同内容或只保留一个
  void queueHighWater();
  void queueLowWater();
  void sendAccepted();          // ack A（P1）
  void sendRejected(const QString& reason); // N 或超次（P1）
};
```

命名实现时可微调，语义保持。

## 6. 关键机要点（P1，写入实现注释）

见 design_02 §4。实现约束：

1. `ackWindow=1`：仅一帧 in-flight。  
2. 超时：独立 `QTimer`，每次发出/重发时重启。  
3. `ackMaxRetry`：建议定义为「最多发送次数」（含首次）；文档与代码注释写死一种。  
4. 收到 A/N：先经 `heartbeatIgnoreMatcher`，再 positive/negative。  
5. 拆帧失败超 `maxFrameSize`：清空缓冲并 `errorOccurred`（不断开或断开可配，P1 默认不断开仅丢弃）。

## 8. 测试计划（审查）

| 用例 | 批次 | 做法 |
|------|------|------|
| 连接成功/拒绝 | P0 | 连存在/不存在端口 |
| 断线重连 | P0 | 杀服务或 disconnect |

| 心跳周期 | P1 | mock 时钟或短 interval 计数 |
| 粘包两帧 | P1 | 一次 write 两帧 LengthPrefix |
| A 后下一条 | P1 | 假对端回 A |
| N 丢弃 | P1 | 回 N |
| 超时重发再丢弃 | P1 | 不回包 |
| 心跳不占窗 | P1 | 业务等 A 时心跳仍发出 |

## 9. 风险与依赖

| 风险 | 应对 |
|------|------|
| 旧工程 A 出队不完整 | P1 按 design 重做，不复制缺陷 |
