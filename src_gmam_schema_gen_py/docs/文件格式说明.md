# GMAM Schema 文本格式说明（草案）

> 与方案设计配套，审查通过后作为读写实现的唯一约定。

---

## 1. 文件形态

- 编码：**UTF-8**（建议无 BOM）  
- 扩展名建议：`.gmam.txt`  
- 行尾：`LF` 或 `CRLF` 均可  

---

## 2. 文件头

前若干行以 `#` 开头为注释或元数据；**必须**出现：

```text
# GMAM Schema
version=1
kind=data
```

或

```text
# GMAM Schema
version=1
kind=header
```

| 键 | 取值 | 说明 |
|----|------|------|
| `version` | `1` | 格式版本，便于以后扩展 |
| `kind` | `data` / `header` | data→FieldDetail；header→HeaderField |

---

## 3. 表头行 + 数据行

表头行（必有，逗号或竖线分隔，**推荐竖线 `|`**，避免与字符冲突）：

### kind=data

```text
name|type|length|scale|rounding|overflow|overflowFill|align|padFill|missingFill|missingPolicy
```

### kind=header

```text
name|type|offset|length|scale|rounding|overflow|overflowFill|align|padFill|missingFill|missingPolicy
```

随后每行一条字段，列数与表头一致。空行忽略。`#` 开头为注释。

---

## 4. 示例（data）

```text
# GMAM Schema
version=1
kind=data
# T9 风格示例片段
name|type|length|scale|rounding|overflow|overflowFill|align|padFill|missingFill|missingPolicy
formId|Chars|10|0|Truncate|Truncate|9|ByType|\0|\0|TreatAsMissing
inputCode|Chars|1|0|Truncate|Truncate|9|ByType|\0|\0|TreatAsMissing
lotNo|Reserved|20|0|Truncate|Error|9|ByType|\0|\0|TreatAsMissing
temp|Numeric|5|3|Truncate|FillChar|9|ByType|\0|\0|TreatAsMissing
cnt|Chars|2|0|Truncate|Truncate|9|Right|\s|\0|TreatAsMissing
code|Chars|4|0|Truncate|Error|9|Left|\s|*|TreatAsMissing
```

---

## 5. 字符列转义（overflowFill / padFill / missingFill）

| 写法 | 含义 |
|------|------|
| `\0` | 哨兵 NUL，表示「按类型默认」（与 C++ `'\0'` 一致） |
| `\s` | 空格 `0x20` |
| `\\` | 反斜杠本身 |
| 单个可见字符如 `9` `*` | 该字符 |
| `\xNN` | （可选）十六进制字节，审查决定是否支持 |

禁止：多字符无转义（如 `ab`）→ 校验错误。

---

## 6. 枚举合法值（大小写敏感，与 C++ 枚举名一致）

| 列 | 合法值 |
|----|--------|
| type | `Numeric` `Chars` `Reserved` |
| rounding | `Truncate` `Round` |
| overflow | `Error` `Truncate` `FillChar` |
| align | `ByType` `Left` `Right` |
| missingPolicy | `TreatAsMissing` `EmptyIsValue` |

---

## 7. 导出 C++ 形态（预览）

由工具生成，例如：

```cpp
QVector<FieldDetail> schema = {
    { QStringLiteral("temp"), FieldType::Numeric, 5, 3, Rounding::Truncate,
      OverflowPolicy::FillChar, '9',
      FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },
    // ...
};
```

header 则生成 `QVector<HeaderField>`，含 `offset`，类型为 `HeaderFieldType::...`。

---

## 8. 校验失败示例

```text
第 5 行：type 非法值 'numeric'（应为 Numeric/Chars/Reserved）
第 6 行：length 必须为正整数
第 7 行：name 重复 'temp'
表头：kind=header 但缺少 offset 列
```
