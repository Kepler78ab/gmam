# GMAM Schema 生成器 — 使用说明（v0.0.2）

## 运行

```bash
cd src_gmam_schema_gen_py
python main.py
```

首次启动会在 **程序目录** 下创建 `lang/zh_CN.json`、`lang/en_US.json`（相对 exe 为 `./lang`；开发时相对本目录）。

## 打包 exe

```bash
pip install -r requirements.txt
python build_exe.py
# 输出：dist/GmamSchemaGen.exe
# 运行后自动在 dist/lang/ 生成翻译文件
```

## 功能（v0.0.2）

- 新建：单选 **data / header**（不再手输）
- 行内编辑；枚举下拉为 **英文码 — 译文**（如 `FillChar — 超额填指定字符`）
- 菜单 **语言**：切换简体中文 / English（读 `./lang/*.json`）
- 表格统一列宽对齐
- 校验、导出 C++（`.gmam.txt` 内仍为英文枚举）

样例：`samples/sample_data.gmam.txt`、`sample_header.gmam.txt`

## 翻译文件

路径：`<exe或main所在目录>/lang/`

| 文件 | 说明 |
|------|------|
| `zh_CN.json` | 简体中文（缺则启动时生成） |
| `en_US.json` | English（缺则启动时生成） |

可改 `ui` / `column` / `enum` 字段后重启或切换语言生效。已存在的文件**不会**被覆盖。

格式细节见 [文件格式说明.md](./文件格式说明.md)。
