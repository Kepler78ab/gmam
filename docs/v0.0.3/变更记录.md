# GMAM v0.0.3 变更记录

## 2026-09-23

- 新增 `FieldAlign` / `MissingPolicy`；`FieldDetail`/`HeaderField` 增加 `align`、`padFill`、`missingFill`、`missingPolicy`
- `resolveFieldStyle`：哨兵 `'\0'` / `ByType` → 类型默认
- 编码按 align+padFill 补位；`OverflowPolicy::Truncate` 跟随 resolve 后的 align
- 缺值 / 失败占位使用 resolve 后的 `missingFill`
- overflow 维持 **P0**（默认 Error，不自动改 FillChar）
- 自测：右对齐 `" 3"`、missingFill `****`、EmptyIsValue
