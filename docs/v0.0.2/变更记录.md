# GMAM v0.0.2 变更记录

## 2026-09-23

- `build(..., QStringList& errors)`：字段级错误收集；删除 `QString&` 单错误接口
- 新增 `GmamError.h`：`formatFieldError` / `failurePlaceholder`
- `encodeField` / `parseNumericString` 改为短 reason，由 Builder 包装完整文案
- 失败字段占位后续跑；有 errors 时仍返回空 buffer
- 自测增加多错误收集用例；smoke / T9 已适配
- 对齐与填充策略仍见 `docs/v0.0.3/`（本包未做）
