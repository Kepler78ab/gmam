# GMAM 使用说明（当前至 v0.0.3）

通用报文组装模块：用 **schema** 描述字段，把 `字段名 → 字符串值` 编成定长 **`QByteArray` 字节流**。

| 版本 | 能力 |
|------|------|
| v0.0.1 | 基础编码、OverflowPolicy、Header/Data/Compose |
| v0.0.2 | `QStringList& errors` 字段级错误收集 |
| v0.0.3 | `FieldAlign` / padFill / missingFill / MissingPolicy |

设计正文：`docs/通用报文组装方案设计/`；分版计划：`docs/v0.0.x/`。

---

## 1. 接入工程

```pro
include(相对路径/module_gmam/module_gmam.pri)
```

```cpp
#include "DataContentBuilder.h"
#include "HeaderBuilder.h"
#include "TelegramCompose.h"
#include "GmamTypes.h"
```

依赖：`QT += core`，C++17。

---

## 2. 整体结构

```text
[头部 head] + [数据内容 data] + [结束符 0x0A]
     ↑                ↑                ↑
 HeaderBuilder   DataContentBuilder   composeTelegram
```

- CRC / 跨段长度等由调用方算好后当普通字段传入。
- 多种报文 = 多套 schema；多层 = 多次 `build` 再 `append`。

## 3. 定义 schema

### 3.1 FieldDetail 参数一览（按直写顺序）

聚合初始化时按下面 **序号顺序** 填写；后面的参数可省略，使用「默认值」列。

```cpp
{ name, type, length, scale, rounding, overflow, overflowFill,
  align, padFill, missingFill, missingPolicy }
```

| # | 参数 | 类型 | 默认值 | 可选值 / 范围 | 意义与作用 |
|---|------|------|--------|---------------|------------|
| 1 | `name` | `QString` | （必填） | 任意字段名 | 与 `values[name]` 对应；错误文案里也会带上 |
| 2 | `type` | `FieldType` | `Reserved` | 见下表 **type** | 决定编码路径：数值 / 字符 / 预留 |
| 3 | `length` | `int` | `0` | 建议 `> 0`；Numeric 另限 `≤ 18` | **固定占位字节数**；编码后长度恒等于它；参与 `totalLength()` |
| 4 | `scale` | `int` | `0` | `≥ 0`；仅 Numeric 有效 | 小数放大：真实值按字符串解析后 ×10^scale，小数点不入报文 |
| 5 | `rounding` | `Rounding` | `Truncate` | 见下表 **rounding** | 仅 Numeric：scale 之后多余小数位怎么处理 |
| 6 | `overflow` | `OverflowPolicy` | `Error` | 见下表 **overflow** | 编码后长度 **> length** 时怎么办（P0：默认报错） |
| 7 | `overflowFill` | `char` | `'9'` | 任意字节字符 | 仅 `overflow == FillChar` 时：整字段填该字符 |
| 8 | `align` | `FieldAlign` | `ByType` | 见下表 **align** | 不足 length 时左贴还是右贴；也影响 `Truncate` 截哪一侧 |
| 9 | `padFill` | `char` | `'\0'` | 任意；`'\0'`=按类型默认 | 不足位补什么字符（N 默认 `'0'`，C 默认空格） |
| 10 | `missingFill` | `char` | `'\0'` | 任意；`'\0'`=按类型默认 | 缺值整段、以及编码**失败占位**填什么（N→`'0'`，C→空格） |
| 11 | `missingPolicy` | `MissingPolicy` | `TreatAsMissing` | 见下表 **missingPolicy** | 「没传 / 传了空串」算不算缺值 |

**Reserved**：一般只需 `name, type, length`；scale/rounding/overflow 等对预留无实际编码作用（始终填空格）。

---

### 3.2 枚举可选项

#### `type` — `FieldType`

| 取值 | 含义 | 编码要点 |
|------|------|----------|
| `FieldType::Numeric` | 数值型 N | 先按字符串解析（拒负数/非法字符）；再按 align+pad 补齐；支持 scale |
| `FieldType::Chars` | 字符型 C | Latin1 字符串；按 align+pad 补齐 |
| `FieldType::Reserved` | 预留 | 忽略 values，输出 `length` 个空格 |

#### `rounding` — `Rounding`（仅 Numeric）

| 取值 | 含义 |
|------|------|
| `Rounding::Truncate` | 小数位直接截断（默认） |
| `Rounding::Round` | 四舍五入 |

与 `OverflowPolicy::Truncate`（超长截断）不是一回事。

#### `overflow` — `OverflowPolicy`

| 取值 | 含义 | 典型用途 |
|------|------|----------|
| `OverflowPolicy::Error` | 记入 `errors`，该字段失败 | **结构体默认（P0）**；严格模式 |
| `OverflowPolicy::Truncate` | 按 **resolve 后的 align** 截到 length | 旧 memcpy 静默截断；左对齐留左、右对齐留右 |
| `OverflowPolicy::FillChar` | 整字段填 `overflowFill` | 协议数值溢出填 `'9'` |

忘记写 overflow → 就是 `Error`。协议要填 9：显式写 `FillChar`，或用 `makeNumericField`（工厂默认 FillChar）。

#### `align` — `FieldAlign`

| 取值 | 含义 |
|------|------|
| `FieldAlign::ByType` | Numeric→右对齐，Chars→左对齐（默认） |
| `FieldAlign::Left` | 左对齐，右侧补 `padFill`；Truncate 时保留左侧 |
| `FieldAlign::Right` | 右对齐，左侧补 `padFill`；Truncate 时保留右侧 |

例：Chars + Right + 空格，值 `"3"`、`length=2` → `" 3"`。

#### `missingPolicy` — `MissingPolicy`

| 取值 | 何时用 missingFill |
|------|-------------------|
| `MissingPolicy::TreatAsMissing` | 无 key，**或** trim 后空串（默认） |
| `MissingPolicy::EmptyIsValue` | **仅**无 key；空串走正常 encode（Chars 常得到全 padFill） |

---

### 3.3 哨兵 `'\0'`（padFill / missingFill）

| 配置值 | Numeric 实际 | Chars 实际 |
|--------|--------------|------------|
| `'\0'`（默认） | `'0'` | 空格 `' '` |
| 其它字符如 `'*'` | 用你写的字符 | 用你写的字符 |

由 `resolveFieldStyle` 在编码时解析。

---

### 3.4 直写模板（复制改）

```cpp
QVector<FieldDetail> schema = {
    // name, type, length, scale, rounding, overflow, overflowFill, align, padFill, missingFill, missingPolicy

    // 数值，三位小数，溢出填 9
    { "temp", FieldType::Numeric, 5, 3, Rounding::Truncate,
      OverflowPolicy::FillChar, '9',
      FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },

    // 字符，超长报错
    { "id", FieldType::Chars, 6, 0, Rounding::Truncate,
      OverflowPolicy::Error, '9',
      FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },

    // 预留 3 字节空格
    { "reserve", FieldType::Reserved, 3, 0, Rounding::Truncate,
      OverflowPolicy::Error, '9',
      FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },

    // 字符，超长静默截左（旧 memcpy 风格）
    { "note", FieldType::Chars, 5, 0, Rounding::Truncate,
      OverflowPolicy::Truncate, '9',
      FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },

    // 字符右对齐补空格："3" → " 3"
    { "cnt", FieldType::Chars, 2, 0, Rounding::Truncate,
      OverflowPolicy::Truncate, '9',
      FieldAlign::Right, ' ', '\0', MissingPolicy::TreatAsMissing },

    // 缺值填 '*'
    { "code", FieldType::Chars, 4, 0, Rounding::Truncate,
      OverflowPolicy::Error, '9',
      FieldAlign::Left, ' ', '*', MissingPolicy::TreatAsMissing },
};
```

只写到 `overflowFill`（前 7 项）也可以，后 4 项用默认：`ByType`、`'\0'`、`'\0'`、`TreatAsMissing`。

### 3.5 工厂（可选，少打字）

```cpp
makeNumericField("temp", 5, 3);              // 默认 FillChar('9')，align/pad/missing 用结构体默认
makeCharsField("id", 6);                     // 默认 Error
makeReservedField("reserve", 3);
makeCharsField("note", 5, OverflowPolicy::Truncate);
```

需要 Right / 自定义 missingFill 时，仍建议直接写 `FieldDetail{ ... }`。

### 3.6 HeaderField（头部）

与 `FieldDetail` **相同语义的参数**，并多一个：

| # | 参数 | 说明 |
|---|------|------|
| — | `offset` | 在头部缓冲区中的起始下标（插在 `type` 之后） |

顺序：

```cpp
{ name, type, offset, length, scale, rounding, overflow, overflowFill,
  align, padFill, missingFill, missingPolicy }
```

`type` 用 `HeaderFieldType::Numeric / Chars / Reserved`。  
未覆盖区间由 `HeaderBuilder(..., holeFill)` 填充。

## 4. 组装数据内容

```cpp
DataContentBuilder builder(schema);   // maxLength 默认 8162

QHash<QString, QString> values;
values["temp"] = "53.167";
values["id"]   = "z01";

QStringList errors;
QByteArray data = builder.build(values, errors);
if (!errors.isEmpty()) {
    qWarning() << "组装失败，共" << errors.size() << "个错误：";
    for (const QString& e : errors)
        qWarning() << "  -" << e;
    return;
}
```

- **成功**：`errors` 为空，`data.size() == totalLength()`。
- **字段级错误**：全部收集；文案形如 `字段 id（第 2 个，Chars）：字符超长（7 > 6)`。
- **整体级错误**（总长 0 / 超 maxLength）：立即返回，通常一条。
- 失败字段会先占位（用 resolve 后的 `missingFill`）再继续遍历；最终因 `errors` 非空仍返回**空** buffer。

## 5. 组装头部

```cpp
QVector<HeaderField> headerSchema = {
    { "sync", HeaderFieldType::Chars, 0, 2, 0, Rounding::Truncate,
      OverflowPolicy::Error, '9', FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },
    { "cmd", HeaderFieldType::Numeric, 2, 1, 0, Rounding::Truncate,
      OverflowPolicy::FillChar, '9', FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },
    { "pad", HeaderFieldType::Reserved, 7, 3, 0, Rounding::Truncate,
      OverflowPolicy::Error, '9', FieldAlign::ByType, '\0', '\0', MissingPolicy::TreatAsMissing },
};

HeaderBuilder headerBuilder(headerSchema, 10, ' ');
QStringList errors;
QByteArray head = headerBuilder.build(hvals, errors);
```

空洞用构造参数 `holeFill` 填充；`offset + length` 不得越界。

## 7. 与旧结构体拼装

旧逻辑多为「`memset(' ')` + 左贴截断」：

- 业务字段：`Chars` + `OverflowPolicy::Truncate`
- 未采集：`Reserved` 或不传值
- 已格式化成带小数点的结果字符串：当 **Chars**，不要标 Numeric
- 右对齐空格个数域：可用 `FieldAlign::Right`，值只传 `"3"`

自测：`gmam_tests` → `gmamCompareT9LegacyVsGmam()`。
