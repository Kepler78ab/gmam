# 模块文件规划（v0.0.1）

对应：`src_gmam_qt/src/module_gmam/module_gmam.pri`  
审定：不合并类型枚举；含 `composeTelegram`；错误为单 `QString` 遇错即返。

## 目录

```text
src_gmam_qt/src/module_gmam/
├── module_gmam.pri
├── GmamTypes.h              # 类型与字段描述（仅头文件）
├── FieldCodec.h
├── FieldCodec.cpp           # 公共编解码
├── DataContentBuilder.h
├── DataContentBuilder.cpp
├── HeaderBuilder.h
├── HeaderBuilder.cpp
├── TelegramCompose.h        # composeTelegram
└── TelegramCompose.cpp      # 若仅 inline，可并入 .h，实现时定
```

## 职责

| 文件 | 职责 | 方案章节 |
|------|------|----------|
| `GmamTypes.h` | `FieldType`、`HeaderFieldType`（分列）、`Rounding`、`OverflowPolicy`；`FieldDetail` / `HeaderField` | §4、§11.3、规则 7 |
| `FieldCodec` | `parseNumericString`；`encodeField`（含超额三策略） | §5、§12 |
| `DataContentBuilder` | 顺序拼接；`maxLength` 默认 8162；`build(values, QString& error)` | §3–§6、§12.5 |
| `HeaderBuilder` | 按 offset 填头；共用 `FieldCodec` | §11 |
| `TelegramCompose` | `head + data + terminator` → `QByteArray` | §3.1 / §7.3 |

## 输出约定

- 成功：`QByteArray`（字节流）
- 失败：空 `QByteArray` + `QString& error`（**首错即返**；§13 多错误收集延后）

## 本版本不纳入

| 项 | 说明 |
|----|------|
| `FieldType` / `HeaderFieldType` 合并 | 基础功能后再评估 |
| §13 `QStringList` 错误收集 | 后续计划包 |
| T9 整包兼容实现 | 旧分析只驱动新特性设计；整包测试留后续 |
| schema 嵌套类型 / 配置加载 | 调用方多次 build + append |
| Excel / DB 业务代码 | 不进 `module_gmam` |
| 校验和 / CRC / 跨段长度 | 调用方传入 |
