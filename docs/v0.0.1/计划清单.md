## 0. 目标与范围

### 0.1 本版目标

- [x] 落地可复用的 **通用报文组装库**（`module_gmam`）
- [x] 输出统一为 **`QByteArray` 字节流**
- [x] 支持 **多种 schema**（换 `QVector<FieldDetail>` / `HeaderField` 即可）
- [x] **分层**：`DataContentBuilder` + `HeaderBuilder`；整包可用 `composeTelegram`
- [x] **规则 7 可配**：`OverflowPolicy` = `Error` / `Truncate` / `FillChar`

### 0.2 本版不做

- [ ] `HeaderFieldType` / `FieldType` 合并（后续再评估）
- [ ] §13 多错误收集（`QStringList& errors`）→ **后续计划包**
- [ ] T9 整包 schema / 逐字节快照对比 → **后续测试阶段使用旧素材**
- [ ] schema 多层嵌套语言 / 配置文件驱动 schema
- [ ] Excel / DB 等业务侧代码迁入本模块
