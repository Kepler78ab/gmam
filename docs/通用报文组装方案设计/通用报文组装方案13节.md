## 13. 错误收集与 debug 输出

> **实现状态**：✅ 已在 **v0.0.2** 落地（`QStringList& errors`）。  
> 本章描述错误处理策略。第 5、6、11、12 章中若仍写“遇错立即返回 / 单条 QString&”，以本章与 v0.0.2 为准。  
> 失败占位字符在 **v0.0.3** 起改为使用 resolve 后的 `missingFill`。

### 13.1 升级动机

原策略：**遇到第一个错误立即返回**，后面的字段不再处理。 问题：debug 时一次只能看到一条错误，改完一个再跑出下一个，效率低。 尤其当多个字段同时有问题时，无法一次看全。 新策略：**字段级错误全部收集，跑完所有字段后汇总返回**。 调用方一次就能看到所有问题，便于集中排查。

### 13.2 错误分级

将错误分为两类，处理方式不同：

| 级别                                                       | 例子                               | 处理方式                           |
| ---------------------------------------------------------- | ---------------------------------- | ---------------------------------- |
| **整体级错误**                                             | schema 总长为 0、数据内容超长      | **立即返回**，不再遍历字段         |
| **字段级错误**                                             | 字段长度非法、非法字符、负数、超长 | **收集后继续**，跑完全部字段再汇总 |
| 理由：整体级错误一旦发生，结果一定不可用，继续遍历无意义； |                                    |                                    |
| 字段级错误彼此独立，可以一起报出来。                       |                                    |                                    |

### 13.3 接口变更

`error` 参数由 `QString&` 改为 `QStringList& errors`。 **`DataContentBuilder`**（替代第 4.3 / 6.1 节定义）：

```
class DataContentBuilder {
public:
    explicit DataContentBuilder(QVector<FieldDetail> schema,
                                int maxLength = 8162);
    // 成功返回数据内容，errors 为空；
    // 失败返回空 QByteArray，errors 列出全部字段级错误
    QByteArray build(const QHash<QString, QString>& values,
                     QStringList& errors) const;
    int totalLength() const { return m_totalLength; }
    int maxLength() const { return m_maxLength; }
private:
    QVector<FieldDetail> m_schema;
    int m_totalLength = 0;
    int m_maxLength   = 8162;
};
```

**`HeaderBuilder`**（替代第 11.4 节定义）：

```
class HeaderBuilder {
public:
    explicit HeaderBuilder(QVector<HeaderField> schema,
                           int totalLength,
                           char holeFill = ' ');
    // 成功返回头部字节，errors 为空；
    // 失败返回空 QByteArray，errors 列出全部错误
    QByteArray build(const QHash<QString, QString>& values,
                     QStringList& errors) const;
    int totalLength() const { return m_totalLength; }
private:
    QVector<HeaderField> m_schema;
    int  m_totalLength = 0;
    char m_holeFill    = ' ';
};
```

### 13.4 组装流程（新）

以 `DataContentBuilder::build` 为例：

```
1. 清空 errors
2. 整体级校验（立即返回）
   ├─ totalLength <= 0       → errors << "...", return {}
   └─ totalLength > maxLength → errors << "...", return {}
3. 遍历 schema 每个字段
   ├─ length <= 0            → 记错误，跳过（无法占位）
   ├─ Reserved               → 填空格，继续
   ├─ 缺值                   → 按类型填默认，继续
   └─ encodeField
        ├─ 成功 → 追加结果
        └─ 失败 → 记错误 + 用占位填充，继续处理下一个字段
4. 遍历结束
   ├─ errors 非空 → return {}（失败）
   └─ errors 为空 → return buffer（成功）
```

关键点：

- **失败字段不中断遍历**，用占位填充，保证 buffer 长度仍为 `totalLength`。
- **整体级错误仍立即返回**，不进入字段遍历。

### 13.5 失败字段的占位策略

字段编码失败时，该字段**占位仍然保留**，填充规则按类型：

| 类型     | 失败时占位填充    |
| -------- | ----------------- |
| Numeric  | `length` 个 `'0'` |
| Chars    | `length` 个空格   |
| Reserved | `length` 个空格   |
| 好处：   |                   |

- `buffer` 长度始终 = `totalLength`，结构完整。
- debug 时能看到“正常字段 + 错误字段占位”的整体样子。
- 最终因 `errors` 非空仍返回空，占位不会被误用。

### 13.6 错误信息格式

每条错误建议包含以下信息，便于定位：

- **字段名**：是哪个字段。
- **字段序号**：schema 中第几个（便于对照 schema 定义）。
- **字段类型**：Numeric / Chars / Reserved。
- **失败原因**：具体错在哪。 示例：

```
字段 temp（第 0 个，Numeric）：含非法字符
字段 volt（第 1 个，Numeric）：数值溢出（length=4, scale=1）
字段 id（第 2 个，Chars）：字符超长（7 > 6）
数据内容超长：9000 > 8162
```

实现建议：

```
errors << QString("字段 %1（第 %2 个，%3）：%4")
          .arg(f.name)
          .arg(fieldIndex)
          .arg(fieldTypeName(f.type))
          .arg(reason);
```

其中 `fieldTypeName` 是一个把枚举转成可读字符串的小工具函数。

### 13.7 调用方使用

```
QStringList errors;
QByteArray data = dataBuilder.build(dataValues, errors);
if (!errors.isEmpty()) {
    qWarning() << "组装失败，共" << errors.size() << "个错误：";
    for (const QString& e : errors)
        qWarning() << "  -" << e;
    return;
}
QByteArray head = headerBuilder.build(headerValues, errors);
if (!errors.isEmpty()) {
    // 同样处理
    return;
}
QByteArray packet = head + data + QByteArray(1, 0x0A);
```

### 13.9 说明

1. **整体级错误仍立即返回**：这类错误下结果不可用，继续遍历无意义。
2. **字段级错误全部收集**：便于一次性 debug。
3. **失败字段用占位填充**：保持 buffer 结构完整，便于定位。
4. **成功判定**：`errors.isEmpty()` 即成功，否则失败并返回空。
5. **接口统一**：`DataContentBuilder` 和 `HeaderBuilder` 都改用 `QStringList& errors`，保持一致。
